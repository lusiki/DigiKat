# Archived design prototype

This is a non-production visual prototype retained for design history. It is intentionally excluded from the
main Quarto render.

The prototype contains illustrative statistics, placeholder team content, bilingual mock copy, and inactive
links. None of those values should be cited as current DigiKat results. The active site source is `index.qmd`,
`pages/`, `_quarto.yml`, and `assets/` at the repository root.

`ORIGINAL_README.md` preserves the prototype's original description. The exact duplicate `tim(1).qmd` was
removed during the 2026-07-28 housekeeping pass; `tim.qmd` is the retained copy.
